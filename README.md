- **Ecosystem Momentum**: Base turned 2 in August, hit 10x faster blocks (200ms via Flashblocks), and launched Base Pay for real-world spending (e.g., Chipotle via Flexa). Onchain Wrapped 2025 tool lets users share yearly activity, boosting engagement.

## All Products: A Comprehensive Overview
Coinbase and Base offer a suite of interconnected products, blending centralized trust with decentralized power. Here's a detailed breakdown:

1. **Base Chain**: Ethereum L2 for low-cost, fast transactions. Features: Native USDC, 125 Mgas/s throughput, 200ms blocks. Use cases: DeFi (Aerodrome $200B+ volume), RWAs (JPMD, S&P assessments), social (Farcaster integrations).
   
2. **Base App**: Mobile-first onchain hub (700K+ waitlist). Products: Mini apps (e.g., Aerodrome swaps, Jooce staking), memecoin pairing, FollowSync from Twitter. Enhances creator economies with refunds, endorsements.

3. **OnchainKit & MiniKit**: Developer toolkits for building apps. OnchainKit: Weekly active apps grew 3x in 2025; MiniKit: Enables quick shipping (e.g., Ethos in <1 hour). Includes MCP tools for appchains.

4. **Coinbase Wallet & Embedded Wallets**: Self-custody with fiat on-ramps. Embedded: Custom wallets in minutes, 4.1% USDC rewards. Supports Base, Solana bridges.

5. **DEX Trading**: In-app access to millions of assets on Base/Solana. Rolled out globally (e.g., Brazil), with 50x leverage on perpetuals.

6. **Crypto-as-a-Service (CaaS)**: Institutional backend for custody, trading, payments. Powers BlackRock ETFs, PNC Bitcoin access, Stripe USDC.

7. **USDC & Stablecoins**: $74B circulation; Rewards up to 4.5% (Coinbase One). Integrations: EURAU, GBP savings (3.75% AER in UK), JPMD.

8. **x402 Protocol**: Open payments standard for AI agents (with Google), global payouts. V2 adds flexibility; Used in Eigen Cloud tournaments.

9. **Coinbase Prime & Institutional Tools**: cbBTC for DeFi; cbXRP/ADA/LTC/DOGE on Base. $448M from Circle distributions.

10. **Coinbase One Card**: 4% BTC back on purchases, Amex network. Waitlist shipped in August.

11. **Prediction Markets & Tokenized Equities (Upcoming)**: Teased for Dec 17; Kalshi integration for bets, RWAs for stocks.

12. **Other**: Base Pay (Shopify/Fexa), Onramp API, Bug Bounty ($5M), Commerce Payment Protocol.

These products form the "Everything Exchange"—trade anything, anywhere, onchain—targeting trillions in RWAs and payments.
